# doc_common

Rust crates shared by DocHelper's per-format engines (`flutter_text_core`,
`flutter_sheet_core`, and the word and slide engines). Written from
scratch; the only dependencies are `flate2` for deflate streams and
`thiserror`.

| Crate | What it does |
| --- | --- |
| `doc_zip` | ZIP read/write for OOXML, ODF and EPUB packages: ZIP64, data descriptors, CP437/UTF-8 names, size limits, raw copying of unchanged entries |
| `doc_xml` | Pull reader, round-tripping element tree, escaping writer, namespace identities (Strict = Transitional OOXML), OOXML `_xHHHH_` strings; never expands DTD entities |
| `doc_encoding` | UTF-8/16/32 and 32 single-byte code pages, with detection; tables generated by `tools/gen_tables.py` |
| `doc_opc` | Document packages (OOXML and ODF): parts, relationships, content types; saving copies every untouched part raw and keeps ODF's `mimetype` first |
| `doc_ffi` | The Rust FFI plumbing every engine uses (`extern "C"` exports for `dart:ffi`; no C code): error codes, panic guards, string/buffer ownership, session handles, atomic file writes |
